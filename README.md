# Ticket Management System

Frontend-only ticket management interface built with React, TypeScript, Vite, Tailwind CSS, React Router, and Lucide React.

## Project structure

- `frontend/` — React application
- `backend/supabase/` — reserved for future Supabase integration
- `docs/` — project documentation

## Frontend development

```bash
cd frontend
pnpm dev
```

Build and type-check from the `frontend` directory:

```bash
pnpm exec tsc --noEmit
pnpm build
```
